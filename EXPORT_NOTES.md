# CV / Academic Review Export

This is a selected review copy of an existing computational research project. Original reports, code, metrics and figures are copied byte-for-byte. No research, training, rescoring or figure generation was performed during packaging. AI assistance and unconfirmed student contributions remain disclosed in the original README/report.

Raw data, virtual environments, caches, full third-party tools, fitted models, large intermediate arrays, superseded experiment directories and historical approval materials are omitted. Source hashes and references to these local files in retained provenance records do not mean the files are bundled. Follow the original acquisition/setup commands to rebuild omitted inputs. Historical paths mentioned in the source README may refer to intentionally excluded local evidence.

EXPORT_MANIFEST.json lists every copied source file and its SHA-256. The report and original scientific conclusions are unchanged. This archive is prepared for CV and academic review, not a publication approval or independent researcher endorsement.

P4: The final compressed predictions contain only binary labels and model scores, without collision identifiers; these modest files and PR-curve coordinates are retained to support the original no-training rescoring commands. Repeat-run prediction copies are omitted. For this export, use the verification command without `--compare repeat-20261021`, or rebuild that comparison run first. The original verification.json already records the completed repeat comparison. No verification command was executed during packaging.
