# P4 executable scripts

Run from the project root with the local Python environment. `acquire.py` checks the fixed official files; `prepare.py` validates dictionary/data and creates deterministic splits; `run.py` trains fixed pilot/final configurations; `evaluate.py` rescores saved predictions; `plot.py` uses CSV tables; `verify.py` independently checks metrics, raw hashes and optional retraining; `tables.py` updates marked report/README tables from final CSVs. Full commands are in the root README.
