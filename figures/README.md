# Computed P4 figures

The authoritative six PNGs are in `final-20261021/`. `inputs.json` records hashes of source tables. Figures are generated by `scripts/plot.py` from saved tables, not manually entered scores. Calibration bins have unequal support; see `results/final-20261021/calibration.csv`. Importance error bars are standard deviations over three validation permutations, not confidence intervals. Original pre-correction figures remain in `original-final-20261021/`.
